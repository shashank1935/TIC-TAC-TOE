# TIC-TAC-TOE
# 🎮 Tic Tac Toe Web App

A simple and interactive **Tic Tac Toe game** built using **HTML, CSS, and JavaScript**. This project is perfect for beginners who want to understand DOM manipulation, event handling, and basic game logic in JavaScript.

---

## 🚀 Features

* 👥 Two-player mode (Player X vs Player O)
* 🔄 Restart / Reset game functionality
* 🎯 Win detection with highlighted results
* 🤝 Draw detection
* 💡 Clean and responsive UI
* ⚡ Instant move updates using JavaScript

---

## 🛠️ Technologies Used

* **HTML** – Structure of the game board
* **CSS** – Styling and layout design
* **JavaScript** – Game logic and interactivity

---

tic-tac-toe/

## 🎮 How to Play

1. Open the game in your browser.
2. Player **X** starts first.
3. Players take turns clicking on empty cells.
4. The first player to align 3 marks (row, column, or diagonal) wins.
5. If all cells are filled and no winner is found, the game ends in a draw.
